# 🧠 Customer Purchase Prediction (ML Project)

## 📌 Project Overview
This project predicts whether a customer will buy a product or not using Machine Learning algorithms.

---

## 📂 Dataset
- Features: Age, Income, Student, Credit Rating
- Target: Buy (0 = No, 1 = Yes)
- Size: 50+ records

---

## ⚙️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## 📊 Exploratory Data Analysis
- Target variable distribution visualized
- Relationship between Age and Purchase analyzed

---

## 🤖 Models Used
1. Logistic Regression
2. Decision Tree Classifier

---

## 📈 Results

| Model                | Accuracy |
|---------------------|----------|
| Logistic Regression | 0.85     |
| Decision Tree       | 0.90     |

---

## 🔍 Key Insights
- Decision Tree performed better on this dataset
- Dataset size impacts model performance
- Visualization helps in understanding patterns

---

## 🚀 Future Improvements
- Increase dataset size
- Try more models (Random Forest, SVM)
